# 物品与机器：原生像素制作规范

2026-11-13修订。默认流程是 **目标画布布局 → 分区域原生绘制 → 合并碎色 → 验收**。本页替代此前物品/机器制作条款；旧实验、统计与高光范例仅按需查阅，不再作为默认工序。人物、UI、宣传图另定规格。

## 默认制作方式

1. 确定实际W×H、功能、结构参考和材质参考。在目标画布分配各部件的坐标范围、留白和主次；先确认轮廓、支撑、连接与取料/操作关系成立。48×64只是本次矿化机规格，不能推广到所有素材。
2. 在Aseprite或等效原生工具按部件分层绘制。可用整数坐标的像素、矩形和多边形批量落笔；每个色块必须有结构或材质用途。没有必要时不先生成高清概念图。
3. 先画大轮廓和承重机壳，再画功能区域与遮挡，最后画少量材质分面、接缝和短高光。已有认可区域局部修改，不整图重新生成。若缩图占错了空间，可以重分配部件与重画轮廓，不能默认锁住自动稿的透明掩膜。
4. 每区画完做减杂色：合并同一平面近似色块；删除没有作用的碎点和重复边线；简化多个部件交界处堆叠的棕灰/高光层次。保留必要灯、孔洞和连接。不能用全图模糊、机械降色或修改像素数替代这一判断。
5. 在1×检查可读性，最近邻整数倍检查色块与连接。技术验收和用户视觉评价分开；发现碎色必须记录并继续在同一源稿上处理，不因色板合规就宣布美术通过。

## 色块与材质

- 色板优先来自同材质原版/MOD参考，新增颜色写明用途。色数只是预算，不以固定22色、固定每材质阶数或色数减少作为质量目标。
- 同一平面底色连续，体积用少量硬边分面表达。金属采用必要短高光、邻接暗面与端部收束，不整圈刷亮边。
- 玻璃优先用不透明离散色块和简短反光表示；晶体靠清楚切面，不画成枝条或发光团。
- 光源与部件形体一致，参考支持的局部反光可不对称。不规定所有45°倒角必最亮、统一圆角阶梯、统一凹凸高光公式或每条亮线多色。
- 内部暗线仅用于遮挡、接合和凹槽；不为每个零件重复包边。禁止渐变、抗锯齿、平滑插值、随机噪点与无用途装饰碎色。

## 保留的交付要求

- 最终PNG实际尺寸必须等于指定W×H；比例相同、命名正确或大图看似像素画均不算达标。
- 独立硬边精灵默认透明背景与内部空隙，Alpha为0/255；需要半透明的任务另定规格。参考原文件只读，不悄悄阈值化。
- 交原尺寸PNG、可编辑分层源稿、色板与用途、区域布局及制作记录；程序落笔时保留坐标/图层记录。源稿重导出逐像素一致。
- 预览只由成品最近邻整数倍放大，明确标注倍率，不能代替原尺寸交付。
- 状态差分从同一母版派生，锁定画布、原点与公共区，允许区外RGBA差异为0。
- 结构、原生可读性、杂色、尺寸、色板、Alpha分别验收；单连通、固定色数、零差异只证明对应技术条件。
- 游戏接入按明确任务执行，另查资源键、Point、PPU、pivot、图集、占格、显示/拖拽/旋转/状态/读档；制作完成不等于部署或游戏验证。

## 仅按明确需求启用

- 概念探索：可生成大图辅助造型决策，保存原稿与实际参数；随后回到目标画布重画，不能只缩小限色修边后交付。
- 旧图转换/恢复：记录源哈希、采样、裁切、Alpha与色板，产物标转换草稿。可信整数网格恢复与普通有损缩图分开。
- 模型直出实验：用户明确只要原图时交未处理文件并报告偏差；后处理不得冒称模型直出。
- 原版结构/高光研究：按实际部件选用范例，不强迫每项任务取样所有坐标、线段或固定颜色排列。
