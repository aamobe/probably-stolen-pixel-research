# 原生像素任务模板

请按本仓库现行美术规范制作[名称/用途]，默认在实际[宽]×[高]画布上直接分区域绘制。

## 先确定
- 设计范围：新设计 / 原版改装 / 已认可造型局部修改。
- 功能部件、结构与材质参考、必须保留和排除的内容。
- 各部件原生坐标范围、轮廓、留白、支撑和连接；区分画布尺寸、主体包围盒与玩法占格。
- 色板来源与用途，光源约定、锁定区域、透明规则。

## 制作
在原生工具中按部件分层落笔，先轮廓与大面，再功能机构，最后必要接缝和短高光。整数坐标批量绘制属于原生制作，不是模型直出。
逐区合并同平面近似颜色，清理无用途碎点、重复描边和交界处过多明暗层次。颜色属于色板仍可能显脏。
不默认生高清图，不默认缩小/量化，不将自动稿轮廓当作必须保留的限制。
概念生成、转换恢复、模型直出测试仅在明确需要时启用，并分别记录阶段。

## 交付和验收
交实际[宽]×[高]透明PNG、可编辑分层源稿、区域布局与颜色用途、必要的最近邻整数倍预览。
实测：宽高、可见RGB数量、色板外像素、Alpha分布、源稿重导出RGBA差异。
视觉检查：1×部件能否辨认，承重与管路是否成立，大面是否连续，交界是否有碎色，高光是否过密。
记录用户评价与剩余问题；不得把文件检查通过写成用户视觉批准。
不自动部署或运行游戏；GitHub同步按用户在当前任务中的授权执行。
