# 验收检查
1. 记录原始文件哈希、真实尺寸和Alpha分布；抠除绿幕后的统计另标，文字要求不能代替参数与实测。
2. 极小参考可整数最近邻放大，验证逐像素复制，保留完整画布和Alpha。
3. 转换记录目标尺寸、算法版本、参数、色板、抠色阈值与人工编辑。自动网格检测不决定游戏尺寸。
4. 原生尺寸检查轮廓、身份标记、部件连接／遮挡／支撑；整数放大检查顶盖、机壳、底座平面连续，无无用途杂色碎点；必要灯、铆钉和材质反光保留。
5. 忠实重绘同时报告Alpha IoU、重叠主体RGB与全画布RGBA一致率；后者包含空白。原版色板映射是条件，不是美感证明。
6. 新设计按功能与可读性评价，不用与参考逐像素相似度奖励照抄。
7. 状态差分保持同母版、画布、原点，允许区域外RGBA差异为0。
8. 当前成果没有用户视觉批准或游戏验证。抠绿阈值不适合绿色主体，色板也不适用于所有材质。
