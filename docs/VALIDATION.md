# 原生制作验收

按 [现行美术规范](ART-STANDARD.md) 分开验收：

1. 实际PNG宽高等于任务规格，Alpha符合约定，色板外像素为0；原版参考保持不变。
2. 1×辨认功能部件，承重连续，连接/遮挡合理；新设计不按与原图逐像素相似度评分。
3. 放大检查同平面连续色块、交界碎色、重复边线与过密高光；灯和必要单像素结构保留。固定色板也可能产生杂色。
4. 分层源稿重导出与PNG逐像素一致，整数倍最近邻预览与原图对应。
5. 用户评价、技术通过、游戏实测分别记录。用户反馈“更好但仍有杂色”不是视觉全部批准。
6. 状态差分允许区外RGBA差异为0；概念图、转换稿、原生稿分别标记，不将后处理称直出。
