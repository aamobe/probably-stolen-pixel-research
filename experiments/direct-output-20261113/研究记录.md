# 原版品质精灵直出研究

目标：由生成工具直接输出具有原版结构、色块、像素连接和透明边缘品质的独立精灵。后处理不能计为直出成功。先分别验证造型、色块／网格、Alpha和实际文件尺寸，再验证新机器能否同时满足。

## 已有基线

- 矿化机第三版获得用户对造型方向的认可，但实际1086×1448，未通过原生网格与平涂检查。
- 第二版强化粗像素后被用户否决：结构被粗描边吞掉，仍有渐变。因此不能把加粗和简化等同于改善像素品质。
- 取消绿幕、启用透明参数后产生了真实透明背景，但主体仍大量部分透明，不能单凭背景透明宣布可用。
- 当前工具schema没有尺寸参数；提示词不能替代实际宽高控制。具体能力边界见上级目录《直出精灵能力边界-20261113.md》。

## A：短提示复现原版炉子

目的：先移除新机器设计负担，检验同一工具对已有低分辨率样本的复现能力。本次是控制样本，不是与以前矿化机测试构成严格单变量对照；参考、造型与提示长度均不同。

输入：仓库 art/evidence/native/Sprite/furnace.png。工具image_gen，transparent_background=true。只用该图作为参考。

实际提示词：

> Faithfully reproduce this original 48×48 game sprite as a native 48×48 transparent PNG. Keep its silhouette, shallow front-above viewpoint, proportions, component positions, one-pixel contours and original palette. This is precise pixel art, not an illustrated or polished version. Every face is a continuous flat color region. Preserve the existing tiny functional marks instead of inventing detail. No gradients, texture, lighting effects or antialiasing. Transparent background and gaps, opaque object. Output only the standalone actual-size sprite, not an enlarged preview.

输出按原字节保存为 A-furnace-transparent.png，无缩放、裁切、限色或Alpha处理。逐像素统计见metrics.json，主体RGB统计口径为Alpha≥128。

| 指标 | 原版输入 | 本次生成 |
|---|---:|---:|
| 文件宽高 | 48×48 | 1254×1254 |
| 主体RGB数 | 9 | 15761 |
| Alpha=0 | 0 | 362247 |
| Alpha=255 | 2024 | 2861 |
| 0<Alpha<255 | 280 | 1207408 |

原版280个低Alpha像素属于导出背景，原有证据记录为Alpha=1；不能与生成图大量主体半透明视为同一种情况，也不能把原图未经处理宣称为Alpha二值成品。

观察：生成图保留了大致部件布局，但色面中有渐变、内部边缘细化，原生尺寸不符。结论仅为这一次短提示复现失败，不能据一次实验断言整个模型没有复现能力。

## 接下来的对照顺序

1. **固定样本**：继续用同一炉子及相同提示骨架；每轮标记只改了什么，不一边改造型一边改渲染要求。
2. **平涂控制**：在A基础上仅增加原图实测调色板与“每个面严格单色”的具体说明，比较连续色面是否改善。色数下降仅为辅助指标，不等于视觉达标。
3. **网格控制**：仅在平涂较稳定后，研究原图逐格关系是否保留，检验边缘位置、线宽及有意义的一像素细节。原生尺寸与逻辑网格分别记录。
4. **透明影响**：若仍无法得到平涂，使用相同样本和提示比较透明／不透明输出，测试问题是否与透明输出路径有关；这只是研究诊断，不恢复绿幕作为正式交付要求。
5. **新造型迁移**：只有控制样本结果可靠后，才迁移到用户认可的矿化机结构。原版复现成功不自动证明新机器设计成功。
6. **重复性**：出现合格样本后，在相同设置下重复验证；单张碰巧成功不称为稳定流程。

停止条件：某次输出已经展示相同失败而没有新的实验变量时，不继续重复加重提示词。如果实际48×64尺寸始终不可控，明确该接口未满足直出尺寸要求，另行评估具备尺寸约束的生成入口，不擅自切换付费API、安装模型或通过后处理冒充成功。

本轮仅完成A实验与能力边界核查；后续对照尚未执行。仓库资产、规范和游戏均未修改。
