# 模型直出与原生像素整理

2026-11-13。现行要求见 [AGENTS.md](https://github.com/aamobe/CorpPresence/blob/1b6d4c780ce25e0f34d36edfdeed3580213d830c/art/AGENTS.md)；本页记录已验证的流程和边界。

## 选择路线

**模型直出**指生成工具返回的原文件。必须直接满足实际W×H、颜色、Alpha和结构要求；复制文件不改变分类，重采样、限色、阈值化或逐像素编辑后则属于后处理。用户只要原图时，不擅自转成另一条路线。

**原生整理**指在最终像素网格完成设计与验收，可从原生绘制开始，也可从保存了参数的有损转换草稿开始。已有验证的矿化机路线是“生成造型 → 确定性转换 → 原生结构整理 → 材质细化”。它不是全自动精灵生成算法。

## 本次证据

| 实验 | 观察 | 能支持的结论 |
|---|---|---|
| 三块红绿蓝纯色 | 排除边缘后仍有40/68/24种RGB，指定色命中均0% | 当前入口的精确色值和平涂不能靠提示保证；不能推广到所有模型 |
| 炉子指定9色和平涂 | 实际1254×1254，Alpha≥128区域15904种RGB，精确色板命中约0.104% | 提示中的48×48不是实际尺寸，透明输出不保证二值Alpha |
| 原版炉子8倍复制再恢复 | 中心采样与中心区域众数恢复RGBA差异0 | 已知规则放大图可复原；不是生成图可复原的证明 |
| 明确孔洞坐标 | 原大图画出九列六行；均匀48×48转换后第二行仅6段，末行消失 | 数量提示和统一网格是不同约束 |
| 有界弹性切格 | 部分行由6段改善为7段，末行仍消失；格宽变为标准格约0.5～1.7倍 | 局部改善伴随形变，不作为本项目默认生产方法 |
| 矿化机 | 48×64、23色、0/255 Alpha；原生编辑净改422/1252主体像素 | 转换加原生整理可交付准确尺寸；约33.71%的像素编辑贡献不能隐去 |

前五项为本次有限样本的观察摘要；仓库内可重跑原版恢复校验与完整矿化机样例，不声称能重现随机生图。源码、输入及完整差分见 [矿化机样例](examples/mineral-native/README.md)。色数和连通数只作技术检查，不是美术质量分。

## 可复用步骤

1. 确定目标真实画布、留白、玩法占格，分别选择结构和材质参考。不能把便携净水器32×32误认成机器净水器48×64。
2. 生成稿保存原字节、提示与工具参数。实测宽高、RGB与Alpha；背景不自动使用绿幕。模型能力不足如实记录，不重复追加同义约束后直接宣布成功。
3. 若走原生整理，先保留造型基线。确认有均匀网格才谈网格恢复；没有证据时把操作称为有损转换。记录采样、相位/裁切、色板来源和Alpha阈值。
4. 选择少量明确方法比较。本例中心采样比众数更保留束带和泵轮；众数可去掉杂色，也会吞细线。转换方法只提供草稿。
5. 在目标网格用Aseprite等工具整理功能连接、支承、线宽、窗框和大平面，再处理材质。已确认造型不反复全图生成。高光按二维小区域组织：短亮带、邻行暗带、端部和接缝，不给每条边刷白或铺噪点。
6. 原始生成层、自动转换层、原生编辑层分别追溯。记录每轮前后RGBA以及最终相对自动稿的净变化，避免重复计数。
7. 验证真实尺寸、色板来源、Alpha、轮廓、改动清单和源稿重新导出。1×检查为主，必要的最近邻整数倍预览另存；运行时只用原尺寸PNG。
8. 游戏接入另做资源键、Point、PPU、pivot、图集、点击/拖拽/旋转/状态及读档检查。素材样例不自动注册为游戏资源。

## GitHub实现经验与限制

- [SpriteGrid源码](https://github.com/marksverdhei/spritegrid/tree/64ab6f38b914d8e4bc7db681a541c898b876a1b1/src/spritegrid)：梯度周期/相位检测适用于已有稳定网格；指定输出分辨率包含恢复后NEAREST缩放，不能证明检测到目标网格。当前源码默认逐通道中位数，与README的几何中位数描述有差别。
- [SpriteFusion Pixel Snapper源码](https://github.com/Hugo-Dz/spritefusion-pixel-snapper/blob/02f9315d73d3219274d17767b36d9a231a6b1f4b/src/lib.rs)：局部弹性切格、RGBA众数及固定色板；局部形变、细线被主色吞没仍需检查。
- [Pixel Art Resampler源码](https://github.com/jiwoo7158/pixel-art-resampler/blob/fb4e9fc1f7798ebb52458860df6788bb76b08866/js/main.js)：指定W×H采样、颜色转换适合作基线；尺寸正确不等于结构正确。其Alpha阈值仅清除低值，不自动将余下像素置255。

本地工具是针对本次验证独立编写的基线，未复制或执行这些仓库代码，不宣称复现完整算法。实测工具局限见 [工具说明](tools/native/README.md)。无明确收益时不无限扫描采样参数；结构在生成阶段已经丢失的，采样无法补回。

## 修正的旧要求

| 旧要求 | 现行处理 |
|---|---|
| 默认纯绿背景 | 独立精灵默认透明；单色不透明背景只按实验或用户指定 |
| 制作中全面禁止缩放与预览 | 原生路线允许记录参数的转换草稿；必要的整数倍检查图另存，不替代交付 |
| 生成精灵就等于直接原生绘制 | 明确模型直出和原生整理，不隐去工具处理及编辑贡献 |
| 光源和高光必须左右完全对称 | 记录光源，局部材质反光服从参考，不强制镜像 |
| 所有内部暗边禁止、斜线只能角接 | 允许表达接合/遮挡的暗线；管路和承重连接须连续 |
| 同一模板在总方案与美术目录重复维护 | 总方案仅路由，本研究仓库唯一完整提示词维护在 docs/PROMPT.md |

这些修正不取消实际尺寸、原版像素锁定、参考保护或游戏验证要求。
