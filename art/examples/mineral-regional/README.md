# 矿化机：原生分区域绘制样例

从空白48×64画布开始，在Aseprite按7个绘制层落笔；没有重新生图、导入旧大图、缩小或量化。整数坐标批量绘制不等于模型直出。

## 区域与色块

主培养舱x8..29/y16..45，料盖x7..31/y4..12，右侧循环机构x33..41/y19..48，取料抽屉x9..29/y49..55，共同底座y56..61。先承重轮廓，再功能部件与遮挡，最后有限高光。此布局和48×64不是所有机器的规格。
棕壳与灰金属主要取自MOD海鲜封装机 seafood_sealer，玻璃和晶体补充了有用途的离散色阶。

## 用户评价和剩余工作

用户反馈“比之前要好，不过还是有些杂色”。这是方向改善，不是完全视觉批准。
交界处仍有过多棕灰层次、碎小反光和重复接缝；后续在同一源稿合并平面颜色、删去无用途碎块，保留功能暗边和短高光。
检查脚本通过不代表以上问题已消失；本次规范重整没有悄悄改动样例像素。
